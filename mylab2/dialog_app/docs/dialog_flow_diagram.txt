                         КЛЮЧЕВЫЕ КОМПОНЕНТЫ
================================================================================

frontend (React)          → UI для ввода/вывода сообщений
main.py                  → API эндпоинты (/dialog, /chat)
_classify_intent()       → Классификация намерения по ключевым словам
_extract_entities()      → Извлечение параметров из текста
_generate_response()      → Генерация простых ответов
LiteratureChatBot        → LLM-обработка сложных запросов
  ├── extract_search_keywords() → Очистка запроса LLM
  ├── retrieve_context()        → Многоэтапный поиск
  └── generate_answer()        → Генерация ответа LLM
LiteratureDataStorage    → Работа с БД корпуса
