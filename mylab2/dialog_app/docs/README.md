# Диалоговая система анализа текстов

## Описание

Веб-приложение для естественно-языкового взаимодействия с системой анализа текстов.

## Структура проекта

```
dialog_app/
├── backend/           # FastAPI сервер
│   ├── main.py        # Основной файл с диалоговой логикой
│   └── requirements.txt
├── frontend/          # React приложение
│   ├── src/
│   │   ├── App.jsx    # Основной компонент
│   │   ├── index.css  # Стили
│   │   └── main.jsx   # Точка входа
│   ├── package.json
│   └── vite.config.js
└── docs/              # Документация
    └── README.md
```

## Запуск

### Backend
```bash
cd dialog_app/backend
pip install -r requirements.txt
python main.py
# Сервер запустится на порту 8002
```

### Frontend
```bash
cd dialog_app/frontend
npm install
npm run dev
# Приложение будет доступно на http://localhost:3001
```

## Функционал

### Команды диалога

1. **Приветствие** - `привет`, `hi`, `hello`
2. **Анализ текста** - `анализируй: [текст]`, `проанализируй: [текст]`
3. **Поиск** - `найди: [слово]`, `search: [слово]`
4. **Статистика** - `статистика`, `stats`, `сколько`
5. **Загрузка текста** - `загрузи: [текст]`, `добавь: [текст]`
6. **Помощь** - `помощь`, `help`, `?`
7. **Очистка** - `очистить`, `reset`, `новый диалог`
8. **Выход** - `пока`, `bye`, `выход`

### Сценарий диалога

```
Начало
    ↓
Приветствие (auto)
    ↓
Получение сообщения от пользователя
    ↓
Классификация намерения (Intent Classification)
    ↓
Извлечение сущностей (Entity Extraction)
    ↓
Обработка запроса
    ↓
Генерация ответа (Response Generation)
    ↓
Вывод ответа пользователю
    ↓
Проверка: Выход?
    → Нет → Повторить с "Получение сообщения"
    → Да → Завершение
```

## API Endpoints

- `GET /` - Корневой эндпоинт
- `POST /dialog` - Обработка диалогового сообщения
- `GET /dialog/state` - Получение состояния диалога
- `POST /dialog/reset` - Сброс диалога
- `GET /intents` - Список всех намерений
